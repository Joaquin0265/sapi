Insumos y umbrales de seguridad

Configure desde aquí el punto de reorden y el nivel crítico de cada insumo. El módulo de Alertas usará estos valores para avisar antes de un quiebre de stock.

Volver al catálogo
Stock mínimo

Punto de reorden. Cuando el stock real baje de este valor, conviene reponer. Ejemplo: 50 kg de harina.

Stock crítico

Nivel de quiebre inminente. Debe ser menor que el mínimo. Ejemplo: 20 kg de harina.

Regla del sistema

Crítico < Mínimo. Si intenta guardar un crítico igual o mayor, el sistema rechaza el cambio y no altera la base de datos.
